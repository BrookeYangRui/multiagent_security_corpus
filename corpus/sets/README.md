# Corpus Set Model

The directories are ordered by methodological role, not by paper topic.

1. `01_search_catalog`: retrieval and screening records; never an analysis denominator.
2. `02_broad_included`: canonical works passing the broad screen.
3. `03_taxonomy_eligible`: peer-first candidates awaiting or passing the strict security gate.
4. `04_adjacent_contextual`: reviewed work outside the strict security denominator.
5. `05_analysis_specific`: claim extraction and prespecified audit contracts.

`SET_MANIFEST.csv` is generated by `scripts/build_corpus_sets.py`. A paper may
support multiple claims and analyses but counts once at work level.
