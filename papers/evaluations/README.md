# Evaluation and Benchmark Papers

This directory contains papers whose primary contribution is a security,
privacy, robustness, trust, or safety evaluation of an LLM multi-agent system.
Directories identify the canonical publication venue; `arxiv/` is reserved for
work without a verified archival version.

Papers whose primary contribution is an attack or defense remain in their
canonical category. Reusable datasets, harnesses, and metrics from those papers
are listed once in `corpus/evaluation_artifacts.csv` and link to the canonical
note.
