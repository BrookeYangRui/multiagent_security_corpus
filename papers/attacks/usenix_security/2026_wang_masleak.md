## Paper Type

Attack; Benchmark; Evaluation; Empirical study

## Scope

### System Studied

Black-box multi-agent applications exposed through a public API, including
synthetic applications and real Coze/CrewAI systems.

### Multi-Agent Dependency

Queries are crafted to elicit, propagate, and retain disclosures from multiple
internal agents, revealing architecture and role-specific proprietary content.

### Application Domain

General-purpose multi-agent application platforms.

## Security Model

- Protected assets: topology, number of agents, system prompts, task instructions,
  and tool usage.
- Threat actor: remote black-box API user.
- Trusted components: internal agents and orchestration are hidden but not
  assumed leak-free.
- Attacker capabilities: submit queries and observe only final outputs.
- Security assumptions: no prior internal architecture or backend-model knowledge.

## Main Contribution

MASLeak is a worm-inspired black-box framework that systematically extracts
multi-agent intellectual property and evaluates leakage on 810 synthetic and
real-world applications.

## Attack or Failure

- Attack surface: public API and internal cross-agent communication.
- Attack mechanism: adversarial queries induce disclosures to propagate and
  survive into the final response.
- System-level failure: cross-principal confidentiality failure.
- Security consequence: extraction of prompts, instructions, tools, and topology.

## Defense

- Defense mechanism: potential defenses are discussed.
- Intervention point: API, message, and output boundaries.
- Required observability: internal provenance and final disclosure content.
- Assumptions: Not reported in the public abstract.
- Limitations: exact defense efficacy requires full-paper extraction.

## Evaluation

- Evaluated systems: 810 synthetic MAS applications plus Coze and CrewAI cases.
- Agent configuration: diverse internal architectures generated by the dataset.
- Dataset or environment: first synthetic dataset of 810 MAS applications.
- Baselines: extraction approaches described in the paper.
- Metrics: IP extraction attack success/accuracy.
- Main results: USENIX reports average success of 87% for prompts/instructions and
  92% for architecture in most cases.

## Relation to Existing Work

- Claimed research gap: no prior systematic practical black-box extraction of a
  full set of MAS proprietary components.
- Closest related work: prompt leakage, model extraction, topology inference, and
  computer-worm propagation.
- Difference from prior work: exploits cross-agent propagation while seeing only
  the system's final output.
