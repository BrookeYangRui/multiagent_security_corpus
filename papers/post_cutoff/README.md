# Post-Cutoff Notes

This directory preserves detailed notes for selected works first retrieved after
the frozen `2026-07-01 00:00 UTC` cutoff. These notes are not part of the
included corpus, related-work synthesis, or any analysis denominator.

The complete watchlist and publication-status record is maintained in
`corpus/post_cutoff_papers.csv`. A later conference or journal publication does
not move a work into the frozen corpus unless it is a canonical version of a
work already eligible before the cutoff.
