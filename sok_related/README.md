# Strongly Related Multi-Agent Security SoKs

This is a supporting literature set, not part of the canonical research corpus
in `corpus/papers.csv`. Its denominator must always be reported separately.

## Inclusion Rule

A work is included only when multi-agent interaction is central to its security,
risk, trust, or governance synthesis. A general LLM-agent security survey does
not qualify merely because it contains a multi-agent subsection.

Use the published version when one exists. If no published version exists, use
the latest exact primary preprint or institutional technical report. Works first
available on or after `2026-07-01 00:00 UTC` must be marked `post_cutoff` even
though this set is searched through the current access date.

## Files

- `papers.csv`: canonical records for this supporting set.
- `references.bib`: citations for included works.
- `exclusions.csv`: close but insufficiently multi-agent-centered surveys.

Every included record must have a note under `papers/surveys/`, a unique BibTeX
entry in this directory, and an evidence-based centrality decision. These works
must not appear in `corpus/papers.csv` or `corpus/references.bib`.
