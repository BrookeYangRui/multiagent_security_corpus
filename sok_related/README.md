# Strongly Related Multi-Agent Security SoKs

This is the 14-work supporting synthesis view delivered with the authoritative
142-work package. Seven records also occur in `corpus/papers.csv`; therefore its
count must never be added to the canonical academic-paper denominator.

## Inclusion Rule

The view contains direct multi-agent security syntheses and the package's
closest agentic-security comparators. `relation_level` and the centrality field
make that distinction explicit.

Use the published version when one exists. If no published version exists, use
the latest exact primary preprint or institutional technical report. Works first
available on or after `2026-07-01 00:00 UTC` must be marked `post_cutoff` even
though this set is searched through the current access date.

## Files

- `papers.csv`: canonical records for this supporting set.
- `references.bib`: citations for included works.
- `exclusions.csv`: reserved ledger for later screening decisions; currently
  empty because the authoritative package supplies the complete 14-work view.

Every record has a note under `papers/surveys/`, a unique BibTeX entry in this
directory, and an evidence-based centrality description. Overlap with
`corpus/papers.csv` is intentional and must be deduplicated in any synthesis.
